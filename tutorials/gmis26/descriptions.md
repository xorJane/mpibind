# Supercomputing Foundations: Extended Edition

## Summary

This full-day workshop provides a comprehensive, hands-on introduction to High-Performance Computing (HPC), from Linux fundamentals and parallel programming with MPI to hardware-aware application execution and AI-enabled scientific data analysis. Participants will learn how modern supercomputers are organized, explore compute node architecture and topology, optimize application performance using hardware affinity and Slurm, and apply these skills to analyze real-world power outage data using parallel computing and K-means clustering. Through interactive exercises on a real HPC cluster, attendees will gain practical experience with the tools and techniques that underpin modern scientific computing, data analytics, and artificial intelligence.

**Audience:** Undergraduate students, graduate students, faculty, and researchers interested in learning the fundamentals of HPC and its applications to scientific computing and data analytics. No prior HPC experience is required, although basic programming experience is recommended.

**Requirements:** Participants must bring a fully charged laptop with Wi-Fi connectivity, a terminal capable of running `ssh`, and a government-issued photo ID to obtain access to workshop computing resources. Accounts providing access to the workshop HPC cluster will be supplied for all hands-on exercises.

# Supercomputing Foundations: Accelerated Edition

## Summary

This half-day workshop provides an accelerated introduction to High-Performance Computing (HPC) through hands-on exercises in Linux, parallel programming with MPI, and AI-enabled scientific data analysis. Participants will learn the fundamentals of using an HPC system before applying these skills to analyze real-world power outage data from the U.S. Department of Energy's EAGLE-I system. Using parallel data processing, visualization, and K-means clustering, attendees will discover how HPC enables scalable machine learning and data analytics while gaining practical experience solving a real scientific problem. This streamlined workshop is ideal for participants seeking a fast-paced introduction to HPC and its role in modern AI workflows.

**Audience:** Undergraduate students, graduate students, faculty, and researchers interested in learning the fundamentals of HPC and its applications to scientific computing and data analytics. No prior HPC experience is required, although basic programming experience is recommended.

**Requirements:** Participants must bring a fully charged laptop with Wi-Fi connectivity, a terminal capable of running `ssh`, and a government-issued photo ID to obtain access to workshop computing resources. Accounts providing access to the workshop HPC cluster will be supplied for all hands-on exercises.
